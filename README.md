# Instant Brand Forge

Generates a brand identity in minutes.

## Features

- Features and how-it-works pages
- Pricing

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/instant-brand-forge.git
cd instant-brand-forge
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
